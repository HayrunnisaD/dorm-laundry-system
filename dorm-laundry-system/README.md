# 🧺 Dormitory Laundry Reservation System

A modern, production-ready laundry reservation and management system designed for student dormitories.

## 🚀 Tech Stack
- **Backend:** Python (FastAPI)
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Containerization:** Docker & Docker Compose
- **Authentication:** JWT (JSON Web Tokens)

## 📌 Project Status
Currently in active development (Phase 4: Implementation).
